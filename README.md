## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js** (v18.0.0 or higher) and **npm** installed on your machine.

### 1. Installation

```bash
# Navigate to project directory
cd arabian-sea-shipping

# Install dependencies
npm install
```

### 2. Run Local Development Server

```bash
npm run dev
```

Open your browser at `http://localhost:5173` to view the website.

---

## 📦 Production Build

To compile and optimize the website for production deployment:

```bash
npm run build
```

To preview the production bundle locally:

```bash
npm run preview
```
